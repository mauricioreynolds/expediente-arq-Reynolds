 # ADR-001
 
**Contexto:**
El sistema de parqueo de Torre Central requiere notificar automáticamente al dueño de un vehículo cuando su estadía supera las 24 horas. El problema principal es evitar que la lógica del parqueo esté acoplada a un canal específico de mensajería (como WhatsApp o correo electrónico).

**Decisión:**
Se decidió implementar el patrón **Observer**. La estadía actúa como el sujeto que emite el evento cuando detecta el exceso de tiempo, y los canales de notificación actúan como observadores suscritos.

**Alternativas consideradas:**
Se consideró colocar llamadas directas a las clases de mensajería dentro del método de control de tiempo. Se descartó esta alternativa porque violaba el principio de responsabilidad única (SRP) y obligaba a modificar el código central del parqueo cada vez que el edificio cambiara de proveedor de notificaciones.

**Consecuencias:**
* **Gano:** Flexibilidad total para agregar o quitar canales de alerta sin modificar la lógica de control del parqueo.
* **Pago:** Se requiere mantener una lista de suscripciones en memoria para gestionar los observadores.
